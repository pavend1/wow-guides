# ЧАСТЬ 1. Для тех, кто играет впервые

## Что вы делаете одной фразой

1. В **[облике медведя](https://www.wowhead.com/ru/spell=5487)** генерируете **ярость** ([Увечье](https://www.wowhead.com/ru/spell=33917), [Взбучка](https://www.wowhead.com/ru/spell=77758), автоатаки).
2. Тратите ярость на **[железный мех](https://www.wowhead.com/ru/spell=192081)** — держите **1+ стак** почти всегда под физ. уроном.
3. **[Взбучку](https://www.wowhead.com/ru/spell=77758)** жмите по кулдауну — урон, кровотечение, ярость.
4. Лишнюю ярость — в **[Смести](https://www.wowhead.com/ru/spell=400254)** / **[Трепку](https://www.wowhead.com/ru/spell=6807)** (урон) или **железный мех** (защита).
5. **[Дубовую кожу](https://www.wowhead.com/ru/spell=22812)** и **[инстинкты выживания](https://www.wowhead.com/ru/spell=61336)** — **до** смертельного удара, не после.

## Первый пул — опенер (AoE, ключи)

Подходит для **Избранника Элуны** и большинства паков.

```
1. Взбучка
2. Увечье
3. Лунный луч (если взяли)
4. Воплощение: Страж Урсока
5. Увечье
6. Железный мех (если <2 стаков)
7. Лунный огонь на недоточных
8. Смести при высокой ярости
9. Увечье / Взбучка по КД
10. Железный мех по мере ярости
```

**Друид Когтя:** на одной цели добавьте **[красную луну](https://www.wowhead.com/ru/spell=1252871)** по КД; раз в **~2 мин** — **[зов старейшего друида](https://www.wowhead.com/ru/spell=319454)** в **облике кошки** (урон), если пул безопасен.

### После опенера

Смотрите **таблицу приоритета** (Часть 2). Главное: **взбучка** по КД, **железный мех** не просаживать, **ярость** не капать.

## Простое правило «что жать сейчас?» (AoE, M+)

Сверху вниз — первое подходящее:

| Приоритет | Условие | Жмите |
|-----------|---------|-------|
| 1 | **Взбучка** готова | **Взбучка** |
| 2 | **Увечье** готово | **Увечье** |
| 3 | **Лунный луч** готов (**Избранник Элуны**) | **Лунный луч** |
| 4 | **Воплощение** готово, жирный пул | **Воплощение: Страж Урсока** |
| 5 | Прок **терзания** | **Терзание** |
| 6 | **>80** ярости, защита ок | **Смести** |
| 7 | **<2** стака **железного меха**, физ. урон | **Железный мех** |
| 8 | **Красная луна** готова (**Друид Когтя**, босс) | **Красная луна** |
| 9 | Нет **лунного огня** на целях | **Лунный огонь** |
| 10 | Нечего выше | **Размах** |

> На **одной цели** (**Друид Когтя**): **красная луна** и аптайм важнее **размаха**; в AoE берите талант **двойной лунный огонь** вместо **красной луны**.

# ЧАСТЬ 2. Таланты, статы, экипировка

## Герой-талант: Друид Когтя vs Избранник Элуны

| | **Друид Когтя** | **Избранник Элуны** |
|---|---|---|
| Когда | Меньшие паки, сильный босс, выше сингл-DPS | Большие пулы, проще старт |
| Плюс | **[Терзание](https://www.wowhead.com/ru/spell=441605)**, **[красная луна](https://www.wowhead.com/ru/spell=1252871)** | **[Лунный луч](https://www.wowhead.com/ru/spell=204066)** часто, сильный AoE, самохил |
| Цикл | Физ. урон + проки | **Взбучка** становится арканой (**лунный зов**), **лунный огонь** разлетается |

**Для ключей:** оба варианта валидны. **Избранник Элуны** — проще и сильнее на **больших** пулах. **Друид Когтя** — если нужен урон на боссе и паки **3–5** мобов.

**Ripweaving (Друид Когтя):** после **6** [увечий](https://www.wowhead.com/ru/spell=33917) с талантом **прилив дикой силы** — короткий заход в кошку (**разрыв**), безопаснее старого catweave. **Catweave только ради DPS в Midnight — проигрыш**, кроме **зова старейшего друида** раз в **2 мин**.

Билды: [Icy Veins — M+ таланты](https://www.icy-veins.com/wow/guardian-druid-pve-tank-mythic-plus-tips)

## Статы

### Главное правило

**Уровень предметов важнее вторичных статов.** Ловкость, выносливость и броня с ilvl — основа. Разница **10+ ilvl** — почти всегда апгрейд.

### Приоритет

**Если умираете (деф):**

```
ilvl > Скорость > Универсальность > Мастерство > Крит
```

**Обычный / оффенс (ключи):**

```
ilvl > Скорость > Универсальность > Крит > Мастерство
```

Все вторички **близки по силе** — не гонитесь за идеальным процентом; **сим** на [Raidbots](https://www.raidbots.com/) при споре.

### Зачем каждый стат в M+

| Стат | Зачем |
|------|-------|
| **Скорость** | Больше **увечий** и **взбучки**, быстрее тики кровотечений, короче ГКД |
| **Универсальность** | И урон, и меньше получаемого урона — «приятный» стат |
| **Крит** | Урон + уклонение |
| **Мастерство** | Больше макс. HP и лечения получаемого (**природа: страж**) |
| **Ловкость** | Урон, броня от **железного меха**, уклонение |

# ЧАСТЬ 3. Кулдауны, утилити, аффиксы

## Кулдауны в ключах

| КД | Когда |
|----|-------|
| **Дубовая кожа** (~**40–60 сек**) | Часто, сглаживание; с **шипами** наносит урон атакующим |
| **Неистовое восстановление** | <**50%** HP, после спайка; **2 заряда** с талантом |
| **Инстинкты выживания** (**2** заряда) | Смертельная механика; не копить «на потом» |
| **Воплощение: Страж Урсока** | Каждый жирный пул; много **увечий** и **взбучки** |
| **Лунный луч** | Вместе с пулом (**Избранник Элуны**) |
| **[Колючий мех](https://www.wowhead.com/ru/spell=155835)** | Перед огромным входящим уроном (генерация ярости) |

**Не складывайте** все защиты на один момент без нужды.

---

## Механика Apex — Дикий страж

После **берсерка** / **воплощения** срабатывает **Дикий страж** (талант Apex): следующие способности могут **повториться**. Сет **4 части** усиливает **смести** / **трепку** / **терзание**. Ротацию почти не меняет — продолжайте жать по приоритету.

- [ ] **Избранник Элуны** (проще) или **Друид Когтя** (урон на боссе)
