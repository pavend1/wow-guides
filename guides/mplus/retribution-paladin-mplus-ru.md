# ЧАСТЬ 1. Для тех, кто играет впервые

## Что вы делаете одной фразой

1. Генерируете **Силу Света** (**КС**, **Удар воина Света**, **Правосудие**, **ИС**, **ББ** и автоатаки с **Крестовыми ударами**).
2. Тратите **СС** на **[Окончательный приговор](https://www.wowhead.com/ru/spell=383328)** (одна цель) или **[Божественную бурю](https://www.wowhead.com/ru/spell=53385)** (**3+** врагов).
3. В бурст (**Храмовник**, M+): **[Гнев карателя](https://www.wowhead.com/ru/spell=31884)** → **[Смертный приговор](https://www.wowhead.com/ru/spell=343527)** (если в билде) → **[Испепеляющий след](https://www.wowhead.com/ru/spell=255937)** → **[Молот Света](https://www.wowhead.com/ru/spell=427453)** → **ОП** / **ББуря** → **[Божественный благовест](https://www.wowhead.com/ru/spell=375576)**.
4. При проке **Искусства войны** — **[Клинок справедливости](https://www.wowhead.com/ru/spell=184575)** **выше** обычного приоритета (apex **[Свет в душе](https://www.wowhead.com/ru/spell=1261113)**).
5. **Не капайте** **5 СС** без плана; **не держите** **ГК** «на идеальный пак» — в ключах лучше лишний бурст на среднем пуле.

> **Воздаяние** в M+ — мощные **всплески** каждые **~1–2 мин** + сильная **групповая утилита** (сейвы, ресс, аура). Урон «между окнами» скромнее, чем у чистых ranged-DPS — это нормально.

## Сила Света на экране

| Ресурс | Правило | Почему |
|--------|---------|--------|
| **СС** (до **5**) | Тратьте на **ОП** / **ББурю** / **МС**; не генерируйте на **5** «просто так» | кап = потеря генерации |
| **ИВ** (прок) | **КС** сразу, даже если **4 СС** — можно «потерять» 1 СС | apex **Свет в душе** + риск перезаписи прока |
| **МС** (**~20 сек** после **ИС**) | **5 СС** → **МС** в окне **ГК** / **СП** | главный урон **Храмовника** |
| **ГК** (**~2 мин**) | Жмите на паке **≥15 сек**; тринкеты **до** или **внутри** | **ГК** усиливает крит и траты **СС** |
| **ИС** (**~45 сек**) | По КД на паке; с **СвВ** — это и есть «мини-**ГК**» | AoE-стан (демоны/нежить) + **МС** |

**[Испепеляющий след](https://www.wowhead.com/ru/spell=255937):** **5 сек** AoE-оглушение только по **демонам** и **нежити** — на таких паках цените стан; на остальных это просто урон + **МС**.

## Простое правило «что жать сейчас?» (M+)

1. **ИВ** на **КС**? → **КС** (даже на **4 СС**).
2. **МС** готов и есть **5 СС**? → **МС** (особенно в **ГК** / **СП**).
3. **ГК** готов и танк держит пак? → **ГК** → **СП** → **ИС** → **МС** → траты **СС**.
4. **3+** врагов? → **ББуря**; иначе → **ОП** на **3–5 СС**.
5. **ИС** / **ББ** по КД — не копите «на босса», если пак живёт **≥10 сек**.
6. **Укор** и **[Слепящий свет](https://www.wowhead.com/ru/spell=115750)** важнее, чем «дожать» последний **ОП** на адде.

# ЧАСТЬ 2. Таланты, статы, экипировка

## Герой-талант: Храмовник vs Вестник Солнца

| | **Храмовник** (*Templar*) | **Вестник Солнца** (*Herald of the Sun*) |
|---|---------------------------|------------------------------------------|
| **M+ по умолчанию** | **да** — **Молот Света**, сильный AoE | чуть проще sustained, меньше пикового бурста |
| **Стиль** | **ИС** → **МС**, **Божественный молот**, cleave от критов | **[Светозар](https://www.wowhead.com/ru/spell=431377)** после **ИС**, сильный **Молот гнева** |
| **Генерация СС** | **Крестовые удары** (*Crusading Strikes*) | **Удары Света** (*Templar Strikes*) |
| **Сильные стороны** | лучший AoE-бурст, funnel с **СП** | ровный ST, меньше «setup» |
| **Слабости** | нужно не забывать **МС** после **ИС** | слабее на разбросанных паках |

## Статы

### Главное правило

**ilvl важнее идеальных вторичных статов.** Сила на 2H-оружии даёт больше, чем на любом другом слоте.

### Приоритет (M+, **Храмовник**)

1. **Сила**
2. **Искусность** — усиливает весь святой урон
3. **Критический удар** — ценнее в AoE (**Wrathful Descent**)
4. **Скорость** — быстрее **Крестовые удары** и КД генераторов
5. **Универсальность**

> Точный порядок вторичек **плавает** от экипировки — для BiS прогоните [Raidbots](https://www.raidbots.com/). Жёстких брейкпоинтов нет.

### Кулдауны — как не терять DPS

- **ГК** — на любом паке **≥15 сек**; внутри — **СП** → **ИС** → **МС** → **ББ**.
- **ИС** / **ББ** — **по КД**, не «копите на босса» в M+.
- С **СП** активным — продолжайте AoE-ротацию; урон **СП** считает весь урон по целям.
- **Шкатулка**: канал **до** **ГК**, не после.

3. **ИС** + **ББ** по КД.
4. Не капите **СС** на AoE — **ББуря** часто важнее «идеального» **ОП**.
