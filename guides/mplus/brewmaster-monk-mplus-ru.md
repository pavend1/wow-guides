# ЧАСТЬ 1. Для тех, кто играет впервые

## Что вы делаете одной фразой

1. Строите ротацию вокруг **[нокаутирующего удара](https://www.wowhead.com/ru/spell=100784)** — между двумя **НУ** вписываете **три** другие способности.
2. Держите **[удар бочонком](https://www.wowhead.com/ru/spell=121253)** по кулдауну — главный урон и сокращение КД **пив** и **перемешивания**.
3. Поддерживайте **перемешивание** почти всегда (**УБ** + **НУ**).
4. **[Очищающий отвар](https://www.wowhead.com/ru/spell=119582)** — не копите **2 заряда**; один держите на всплеск **раскачивания** (иконка светится).
5. **[Укрепляющий отвар](https://www.wowhead.com/ru/spell=115203)** и **[призыв Нюцзао](https://www.wowhead.com/ru/spell=132578)** — **до** смертельного удара, не после.

## Раскачивание и «пиво» — простыми словами

| Что происходит | Смысл |
|----------------|--------|
| Удар по вам | Часть урона **сразу**, часть — **раскачивание** (тиками **0,5 сек** ~**10 сек**) |
| Цвет дебаффа | Зелёный → жёлтый → **красный** (тяжёлое раскачивание ≈ **60%+** макс. HP за время тика) |
| **ОО** | Мгновенно «очищает» **50%** **ещё не нанесённого** отложенного урона |
| **Перемешивание** | Пока бафф активен, **больше** нового урона уходит в отложенную часть |
| **Лапа тигра** / **УБ** | Каждая **−1 сек** КД пив; **УБ** ещё **−3 сек** |

**Правило для ОО:** не держите **оба** заряда; один — на «пик» раскачивания (иконка **ОО** светится), второй — когда почти готов новый заряд.

## Первый пул — опенер (AoE, ключи)

Подходит для **Шадо-Пан** и большинства M+ паков (по [Icy Veins — opener](https://www.icy-veins.com/wow/brewmaster-monk-pve-tank-rotation-cooldowns-abilities)).

```
1. (опц.) Пламенное дыхание за ~3 сек до пула — бафф «обожжённые страсти»
2. Порыв нефритового ветра ×2 за 2 сек до контакта
3. Выброс ци в движении к паку
4. Удар бочонком в движении (+ Вызов при необходимости)
5. Нокаутирующий удар
6. Пламенное дыхание
7. Лапа тигра
8. Взрывной бочонок ИЛИ Призыв Нюцзао
9. Удар бочонком
10. Нокаутирующий удар
11. Второй из п.8 (что не жали)
12. Дальше — таблица приоритета ниже
```

При **сборе** нескольких групп можно **1–2** раза **[танцующий журавль](https://www.wowhead.com/ru/spell=101546)** в движении (даёт **перемешивание**), затем обычный опенер.

## Простое правило «что жать сейчас?» (AoE, M+)

Упрощённый приоритет после опенера (полный список — на Icy Veins):

| Приоритет | Условие | Жмите |
|-----------|---------|-------|
| 1 | **Нюцзао** активен (**Шадо-Пан**) | **Пламенное дыхание** → **Удар бочонком** (сброс ПД) |
| 2 | **Нюцзао** / **Взрывной бочонок** готовы, пул **≥25 сек** | **Призыв Нюцзао** или **Взрывной бочонок** |
| 3 | **Нокаутирующий удар** готов | **НУ** |
| 4 | **Удар бочонком** готов | **УБ** |
| 5 | **Пламенное дыхание** (дот/бафф) | **ПД** |
| 6 | **ОО** светится / 2-й заряд почти готов | **Очищающий отвар** |
| 7 | Щит / **решительность** не на КД, не умираете | **Укрепляющий отвар: решительность** |
| 8 | **>80** энергии, всё выше на КД | **Лапа тигра** (оставьте энергию на **УБ**) |
| 9 | Сбор мобов | **Танцующий журавль** (не спамьте подряд) |

> **Главное:** всегда хватало энергии на **удар бочонком**. Ротация = **НУ** + **3** способности + снова **НУ**.

# ЧАСТЬ 2. Таланты, статы, экипировка

## Герой-талант: Шадо-Пан vs Мастер гармонии

| | **Шадо-Пан** | **Мастер гармонии** |
|---|---|---|
| Когда | **Стандарт M+**, паки **3+**, проще | Высокие ключи, **приоритетная** цель, коорд. пулы |
| Плюс | Чаще **Нюцзао**, сильный AoE (**тень на поле боя**), проще | Сильнее **НУ** + **лапа тигра** на 1–2 цели, **выброс ци** |
| Минус | Меньше урона на **1–2** цели | Жёстче позиционирование (**перегружающая сила**) |

**Для ключей:** начните с **Шадо-Пан** (рекомендация Icy Veins для обычного M+). **Мастер гармонии** — если группа делает огромные пулы на высоких ключах и вы уверены в **нокаутирующем ударе** + **комбо нокаута**.

Билды: [Icy Veins — M+ таланты](https://www.icy-veins.com/wow/brewmaster-monk-pve-tank-mythic-plus-tips)

## Статы

### Главное правило

**Уровень предметов важнее вторичных статов.** Ловкость даёт урон, уклонение, **% раскачивания** и силу атаки.

### Приоритет

**Если умираете (деф):**

```
ilvl > Крит > Универсальность > Мастерство > Скорость
```

**Обычный / урон (ключи):**

```
ilvl > Крит > Мастерство > Универсальность > Скорость
```

Все вторички **близки** — **сим** на [Raidbots](https://www.raidbots.com/) при споре. Кольца/шея/плащ без ловкости — подбирайте по таблице выше.

### Зачем каждый стат в M+

| Стат | Зачем |
|------|-------|
| **Крит** | Урон; с **небесной удачей** — сильнее хил и щиты |
| **Универсальность** | Урон + меньше получаемого |
| **Мастерство** | **Уклонение** (стаки с **НУ**); сила атаки |
| **Скорость** | Реген **энергии**, чаще **лапа** / **УБ** (ГКД всё равно **1 сек**) |
| **Ловкость** | Урон, раскачивание, уклонение |

# ЧАСТЬ 3. Кулдауны, утилити, аффиксы

## Кулдауны в ключах

| КД | Когда |
|----|-------|
| **Очищающий отвар** | Пик **раскачивания**; не **2** заряда простаивают |
| **Укрепляющий отвар: решительность** | Часто / перед спайком (если взяли) |
| **Укрепляющий отвар** | Смертельная механика |
| **Призыв Нюцзао** | Жирный пул (**≥25 сек** боя); внутри — **ПД** + **УБ** |
| **Взрывной бочонок** | С **порывом нефритового ветра**; сброс **УБ** |
| **Смягчение удара** / **Распыление магии** | Физ. / маг. спайк (таланты) |
| **Устранение вреда** | **3+** сферы, низкое HP |

**Не складывайте** все защиты на один тик без нужды.

## Кайт (отбегание)

Пивовар **быстрый**: **кувырок**, **удар летящего змея**, пассивная скорость группы. Если агро потерян — не паникуйте: **вызов**, **круг мира**, **паралич**, **Нюцзао** (топот). На высоких ключах кайт — нормальная часть выживания.
