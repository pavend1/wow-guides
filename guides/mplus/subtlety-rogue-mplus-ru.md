# ЧАСТЬ 1. Для тех, кто играет впервые

## Что вы делаете одной фразой

1. Играете **циклами по ~90 сек**: **[Теневые клинки](https://www.wowhead.com/ru/spell=121471)** + **два** **[Танца теней](https://www.wowhead.com/ru/spell=185313)** — это весь ваш урон.
2. Внутри **ТТ** жмёте **[Тайный прием](https://www.wowhead.com/ru/spell=280719)** и финишеры на **6+ ОС**; вне окна — спокойно копите **ОС** и **Техт.**
3. В AoE (M+) генерируете **ОС** через **[Шквал сюрикэнов](https://www.wowhead.com/ru/spell=197835)**; при **≤3** целях можно **[Удар Тьмы](https://www.wowhead.com/ru/spell=185438)**.
4. **Не капайте** **[Теневые клинки](https://www.wowhead.com/ru/spell=121471)** «на идеальный пак» — в ключах лучше лишний раз на среднем паке, чем простой.
5. Утилита разбойника ( **[Уловка](https://www.wowhead.com/ru/spell=1966)**, **[Плащ теней](https://www.wowhead.com/ru/spell=31224)**, **[Скрывающий покров](https://www.wowhead.com/ru/spell=114018)** ) — сильная; не забывайте про **[Пинок](https://www.wowhead.com/ru/spell=1766)** на фокус.

> **Скрытность** в M+ — не «равномерный AoE», а **взрывные окна** на приоритетных целях и жирных паках. Слабый sustained cleave компенсируется огромным бурстом.

## Энергия и очки серии

| Ресурс | Правило | Почему |
|--------|---------|--------|
| **ОС** (до **6–7**) | В **ТТ** тратьте на **6+**; перед **ТТ** можно **намеренно** не финишить пару секунд | больше стаков **Техт.** → сильнее **ТП** |
| **Энергия** (100–200) | Вне **ТТ** не обязаны забивать каждый ГКД — это нормально | в **ТТ** энергии хватает на спам |
| **Техт.** (стаки) | В бурсте старайтесь тратить стаки **финишерами** с баффом **Древних искусств** | apex возвращает **ОС** и вызывает клонов |
| **ТК** (**~90 сек**) | Всегда **2× ТТ** внутри; не начинайте **ТТ**, если до конца **ТК** &lt; **10 сек** | иначе потеряете второй танец |

**[Теневая техника](https://www.wowhead.com/ru/spell=196911):** «случайные» лишние **ОС** — это стаки этой механики. В **[Танце теней](https://www.wowhead.com/ru/spell=185313)** с талантом **Тенековка** (*Shadowcraft*) **Техт.** прокает чаще — не снимайте в M+.

## Кнопки на панели — что делает каждая

| Приоритет | Способность | Когда |
|-----------|-------------|-------|
| Цикл | **ТК** + **2× ТТ** | на паке, который живёт **≥15 сек**; тринкеты внутри |
| В **ТТ** | **ТП** | **6+ ОС**, **ТП** готов |
| В **ТТ** | **ТК** | если ещё не жали в этом окне |
| Финишеры | **Потр.** / **ЧП** / **УМ** | **6+ ОС**; **ЧП** при **4+** врагах |
| Генераторы | **УТ** / **ШС** / **УС** | **УТ** в **ТТ**; **ШС** в AoE; иначе **УС** |
| Между бурстами | **УС**, редкий **УТ** | копите **ОС** и стаки **Техт.** |
| Утилита | **Пинок**, **Ослепление**, **Уловка** | по механикам недели |

## Первый пул — опенер (M+)

Перед боем: **[Незаметность](https://www.wowhead.com/ru/spell=1784)**, **[Смертоносный яд](https://www.wowhead.com/ru/spell=2823)** + **[Замедляющий яд](https://www.wowhead.com/ru/spell=5761)** (M+ по умолчанию).

**Обманщик (стандарт M+):**

1. **[Незаметность](https://www.wowhead.com/ru/spell=1784)**.
2. **[Удар Тьмы](https://www.wowhead.com/ru/spell=185438)**.
3. **[Исчезновение](https://www.wowhead.com/ru/spell=1856)** → ещё **[Удар Тьмы](https://www.wowhead.com/ru/spell=185438)**.
4. **[Удар в спину](https://www.wowhead.com/ru/spell=53)** до **7 ОС** (если в билде — семь точек).
5. **[Потрошение](https://www.wowhead.com/ru/spell=196819)**.
6. Тринкеты / зелье / расовые (**~1–2 сек** раньше, если тринкет даёт **скорость** — баг с **[Сгущающимися тенями](https://www.wowhead.com/ru/spell=185314)**).
7. **[Танец теней](https://www.wowhead.com/ru/spell=185313)** → **[Теневые клинки](https://www.wowhead.com/ru/spell=121471)**.
8. **[Удар Тьмы](https://www.wowhead.com/ru/spell=185438)** → **[Тайный прием](https://www.wowhead.com/ru/spell=280719)**.
9. Дальше — [приоритет ротации](#приоритет-ротации-кратко); второй **ТТ** до падения **ТК**.

**Ловчий смерти:** начните с **[Удар Тьмы](https://www.wowhead.com/ru/spell=185438)** (метка), дальше как выше; в AoE — **[Шквал сюрикэнов](https://www.wowhead.com/ru/spell=197835)** вместо **УТ** при **4+** целях.

> За **~20 сек** до пула можно один раз нажать **ТТ** для **[Суперзарядки](https://www.wowhead.com/ru/spell=470347)** (*Supercharger*) — если взяли в билде.

## Простое правило «что жать сейчас?» (M+)

1. **ТК** готов и танк держит пак? → **ТТ** → **ТК** → **ТП** (не ждите «идеала»).
2. Внутри **ТТ**: **ТП** на **6+ ОС** → **УМ** → **ЧП** (много целей) / **Потр.** → **УТ** / **ШС**.
3. До второго **ТТ**: не начинайте, если **ТК** &lt; **10 сек** осталось.
4. Между бурстами: **УС** / **ШС**; не капите **ОС** без нужды.
5. **Пинок** и утилита важнее, чем «дожать» последний **УС** на адде.

# ЧАСТЬ 2. Таланты, статы, экипировка

## Герой-талант: Обманщик vs Ловчий смерти

| | **Обманщик** (*Trickster*) | **Ловчий смерти** (*Deathstalker*) |
|---|---------------------------|-------------------------------------|
| **M+ по умолчанию** | **да** — сильный AoE и проще бурст | чуть сильнее **одна цель**, слабее на паках |
| **Стиль** | **ТП**, **ТК**, **ТТ**, взрывной cleave | **[Метка ловчего смерти](https://www.wowhead.com/ru/spell=1273061)**, **[Падение (не)достойных](https://www.wowhead.com/ru/spell=328086)** |
| **Сильные стороны** | лучший AoE, меньше требований к статам (**~700** скорости) | приоритетный урон по метке |
| **Слабости** | слабее чистый ST на боссе | нужно **~1100** скорости; провал на разбросанных паках |

**Импорт (M+, Обманщик, AoE):**

В **ТТ** старайтесь финишить с активным баффом «теневого свечения» на экране.

## Статы

### Главное правило

**ilvl важнее идеальных вторичных статов.** Кинжал в оффханде — **только кинжал** (быстрее автоатаки → больше **Техт.**).

### Приоритет (M+, **Обманщик**)

1. **Ловкость**
2. **Скорость** — ориентир **~700** рейтинга (два доп. ГКД в **ТТ** + синхрон **ТП**)
3. **Искусность** — сильнее в AoE, часто выше крита
4. **Критический удар**
5. **Универсальность**

### Приоритет (M+, **Ловчий смерти**)

1. **Ловкость**
2. **Скорость** — ориентир **~1100** (иначе герой слабее Обманщика)
3. **Искусность**
4. **Критический удар**
5. **Универсальность**

> **Скорость** через **[Сгущающиеся тени](https://www.wowhead.com/ru/spell=185314)** удлиняет **ТТ** — on-use с **скоростью** (например, **[Стяг отряда Света](https://www.wowhead.com/ru/item=249344)**) жмите **чуть раньше** опенера.

## Приоритет ротации (кратко)

### Обманщик — single target (приоритетная цель)

1. **ТТ** при **6+ ОС** и готовом **ТП** (или активных **ТК**).
2. **ТТ** при **≤2 ОС** и готовом **ТП** / **ТК**.
3. **ТК** внутри **ТТ**.
4. **ТП** в **ТТ**, **6+ ОС**.
5. **УМ** при **6+ ОС**.
6. **Потр.** при **6+ ОС**.
7. **УТ**, иначе **УС**.

### Обманщик — AoE (M+, **4+** целей)

1. **ТТ** / **ТК** / **ТП** — как в ST.
2. **ЧП** при **6+ ОС**.
3. **Потр.** при **П(н)Д** (Ловчий) или **6+ ОС**.
4. **УМ** при **6+ ОС**.
5. **ШС**; при **≤3** целях — **УТ**, если доступен.
6. Вне **ТТ** — **ШС** / **УС**.

### Ловчий смерти — отличия

- Всегда открывайте пул **[Ударом Тьмы](https://www.wowhead.com/ru/spell=185438)** (**МЛС**).
- После снятия метки — **[Падение (не)достойных](https://www.wowhead.com/ru/spell=328086)** → мощное **Потрошение**.
- AoE: **ШС**; **УТ** только при **≤3** целях.
