# ЧАСТЬ 1. Для тех, кто играет впервые

## Что вы делаете одной фразой

1. Генерируете **Силу Света** способностями.
2. Тратите её на **Щит праведника** — держите бафф почти **всё время боя**.
3. Стоите в **Освящении** (или кладёте его под ноги).
4. Бьёте по **приоритету** — сверху вниз, первое доступное.
5. **Торжество** — в основном **бесплатно** (прок **Яркий Свет**), не тратьте Силу Света на хил без нужды.

Это весь цикл. Всё остальное — уточнения.

---

## Две «валюты» на экране

| Ресурс | Название | Зачем |
|--------|----------|-------|
| Сила Света | Максимум **5**. Тратится по **3** на [Щит праведника](https://www.wowhead.com/ru/spell=53600) или [Торжество](https://www.wowhead.com/ru/spell=85673). **Не капайте на 5** — это потеря. |
| Щит праведника | Бафф после каста | Длится **4.5 сек** за каждый каст. Даёт **броню** (от силы) и **урон** в конус перед вами. Каст **вне ГКД** (глобального времени восстановления). |

**Правило:** кастуйте **Щит праведника** при **3–5** Силы Света. Не кастуйте при ровно **3**, если сразу после понадобится ещё один щит под удар.

## Первый пул — нажимайте именно так

### Шаг 0. Перед пулом

- Положите **Освящение**, если мобов **тянут к вам**.
- Если взяли **Божественный молот** — ударьте им для 1 Силы Света.
- **Длань расплаты** — старт пула.

### Шаг 1. Опенер (стартовая ротация)

```
1. Гнев карателя
2. Божественный благовест
3. Молот Света
4. Щит праведника
5. Щит мстителя
6. Щит праведника
7. Молот гнева / Правосудие
8. Щит праведника
9. Молот гнева / Правосудие
10. Щит праведника
11. Божественный молот
12. Божественный молот
13. Молот праведника
14. Молот праведника
15. Щит мстителя
16. Щит праведника
```

### Шаг 2. После опенера

Смотрите **таблицу приоритета** ниже (Часть 2). Главное: **Щит праведника** почти всегда, **не капать 5 Силы Света**, **стоять в Освящении**.

# ЧАСТЬ 2. Таланты, статы, экипировка

## Герой-талант: Храмовник vs Кузнец Света

| | **Храмовник** | **Кузнец Света** |
|---|---|---|
| Когда | Основной выбор для ключей | Старт в M+, проще ротация |
| Плюс | Больше урона → быстрее ключ | Больше групповой пользы, проще |
| Цикл | **Божественный благовест** + **Гнев карателя** → **Молот Света** каждую минуту | **Яркий Свет** чаще уходит в хил с пользой для геро-таланта |

**Для ключей:** **Храмовник** — дефолт, когда знаешь подземелья. **Кузнец Света** — пока учишься.

**Свап по комфорту:** [Часовой](https://www.wowhead.com/ru/spell=389539) вместо **Гнева карателя** — меньше урона, больше времени с защитными баффами на высоких ключах.

**Полезные свапы под подземелье** (взять очки из талантов класса / спека):

- **Изгнание зла** — мгновенное убийство не-элитной нежити при <30% здоровья
- [Освящённая земля](https://www.wowhead.com/ru/spell=204054) — замедление под ногами
- [Последний бой](https://www.wowhead.com/ru/spell=204077) — таунт по области с **Божественным щитом**
- **Благословение заклинательной защиты** — иммун магии союзнику (часто хилу)

Билды: [Icy Veins — M+ таланты](https://www.icy-veins.com/wow/protection-paladin-pve-tank-mythic-plus-tips)

## Статы

### Главное правило

**Уровень предметов важнее вторичных статов.** Сила и выносливость с ilvl — основа выживания. Две вещи **одного уровня** — тогда смотри приоритет ниже.

### Приоритет

**Если умираете слишком быстро (деф):**

```
Скорость > Универсальность > Мастерство > Крит
```

**Обычный / оффенс (ключи):**

```
Скорость > Крит > Универсальность > Мастерство
```

### Зачем каждый стат в M+

| Стат | Зачем |
|------|-------|
| **Скорость** | Больше **Щитов праведника**, плавнее урон. ~**20%** — нормальный аптайм щита; ~**25–30%** — можно иногда **Торжество** без просадки щита |
| **Крит** | Даёт **парирование**. В ключах много физ. ударов с разных сторон → ценнее, чем на одном боссе |
| **Мастерство** | Блок физики + **2× блок магии**. 100% блок заклинаний ≈ **2726** рейтинга (2575 с Skyfury). 100% физ. блок недостижим |
| **Универсальность** | И урон, и снижение получаемого; слабее мастерства из‑за отсутствия блока |
| **Сила** | Броня от **Щита праведника**, урон, немного парирования |

**Не гонитесь за 100% блока заклинаний** — в ключах скорость и уровень предметов почти всегда выигрывают.

**Сим:** оффенс — [Raidbots](https://www.raidbots.com/). Деф-симы для танков ненадёжны.

**Сокеты:** в **первый** сокет — [Непостижимый алмаз Вечной Песни](https://www.wowhead.com/ru/item=240983); во **все остальные** — [Безупречный хризолит искусности](https://www.wowhead.com/ru/item=240892) (мастерство). Доп. сокеты — через **сияющий связующий камней** (токены из сундука).

**Плащ / запястья / шея** — отдельных «лучших» чар в гайде нет; ставь то, что даёт сила / скорость / мастерство с АХ, если есть.

# ЧАСТЬ 3. Кулдауны, утилити, аффиксы

## Кулдауны в ключах

| КД | Когда |
|----|-------|
| **Ревностный защитник** (1.5 мин) | Часто. «Ошибка прощения», обман смерти |
| **Защитник древних королей** (3 мин) | Большой пак, опасная способность |
| **Гнев карателя** (1 мин) | Каждый серьёзный пул + **Божественный благовест** |
| **Божественный щит** | Снять дебафф / иммун. С **Последним боем** — таунт по области |
| **Благословение защиты** / **заклинательной защиты** | Механики, аффиксы, спасение союзника |
| **Жертвенное благословение** | Снять урон с союзника |
| **Очищение от токсинов** | Почти везде; аффикс **Пожирание** |
| **Возложение рук** | Экстренный хил (себе или союзнику) |

**Ревностного защитника не копите** — лучше использовать, чем умереть с двумя зарядами «на потом».

## Механика Авангард (талант Apex)

**[Слава авангарда](https://www.wowhead.com/ru/spell=1267211)** — усиление таланта (*Apex*):

1. **Правосудие** / **Молот гнева** → прок **Авангард**.
2. Следующий **Щит мстителя** бьёт по **линии** через всех врагов и даёт до **3 Силы Света**.
3. Сразу после — **Щит праведника**.
4. В **Гневе карателя** каждый **Щит мстителя** получает Авангард.

В **Гневе карателя** + **Божественный благовест** — очень много Силы Света. Не капайте и не теряйте аптайм **Щита праведника**.

## Утилити в ключах

| Способность | Зачем |
|-------------|-------|
| **Щит мстителя** | Прерывание + **3 сек тишины** → один кастер почти полностью под контролем |
| **Укор** | Ближнее прерывание |
| **Молот правосудия** | Стан (часто с **Кулак правосудия**) |
| **Ослепляющий свет** | Остановка по области (аффикс **Вознесённые**) |
| **Изгнание зла** | Испуг + мгновенное убийство не-элиты <30% здоровья (нежить) |
| **Заступничество** | Воскрешение в бою |
| **Аура благочестия** | −3% урона группе |
| **Благословение свободы** | Аффикс **Пульсар**, корни |

## Аффиксы

| Аффикс | Что делать |
|--------|------------|
| **Вознесённые** | **Ослепляющий свет**, **Волшебный поток** (кровавый эльф), стан / укор / щит |
| **Связанные с Пустотой** | Убить эмиссария на тебе — просто бурст |
| **Пульсар** | Собирать орбы, [Божественный скакун](https://www.wowhead.com/ru/spell=190784) / **Благословение свободы**; не забыть **Освящение** |
| **Пожирание** | **Очищение от токсинов**, **Торжество** / **Возложение рук**. **Не** **Божественный щит** (группа не получит стак «Затяжная Пустота») |

## Шпаргалка перед ключом

- [ ] **Храмовник** (или Кузнец Света, если учишься)
- [ ] Уровень предметов > вторичные статы
- [ ] **1-минутный цикл:** Гнев карателя + Божественный благовест + Молот Света на жирные пулы
- [ ] **Щит праведника** почти всегда; **Торжество** — по **Яркий Свет**
- [ ] **Щит мстителя** — контроль кастеров, не только урон
- [ ] **Ревностный защитник** — спам; **Защитник древних королей** — планируй
- [ ] Фарм: **Академия Алгет'ар**, **Престол Триумвирата**, **Узел Нексуса Зенас**
