# ЧАСТЬ 1. Для тех, кто играет впервые

## Что вы делаете одной фразой

1. Копите на цели стаки **Заморозки** (**ЛС** / **СЛО**, **МЛ**, **ЛШ** и др.).
2. Тратите стаки **Ледяным копьём** (**6+** стаков у **Чаромета**, **10+** у **Ледяного огня**) или по проку **Ледяные пальцы**.
3. По проку **Заморозка мозгов** жмите **Шквал**; с талантом **Ледяная Бездна** — следите, чтобы **ЛК** съедал больше стаков.
4. **Морозный луч** и **Ледяной шар** — по кулдауну; **МЛ** лучше кастовать **после** расхода стаков, а не в пустую.
5. В M+ почти всегда бьёте **одну приоритетную цель**; AoE идёт от **Разрушения** и cleave. Полноценный AoE-режим — с **3+** целей.

## Механика «Заморозка» и проки

| Элемент | Правило | Почему |
|---------|---------|--------|
| **Заморозка** (до **20** стаков) | Кап **20** — переполнение неизбежно; не паникуйте | главный ресурс урона |
| **ЛК** | **Чаромет:** **≥6** стаков или **ЛП**; **Ледяной огонь:** **≥10** или **ЛП** | максимум **Разрушения** |
| **ЛП** | **ЛК** бьёт как при полных стаках, **не снимая** дебафф | жмите сразу |
| **ЗМ** | **Шквал** по проку; с **ЛБ** — удваивает расход стаков следующим **ЛК** (**8 сек**) | синергия с **ЛП** — до **12** стаков урона без снятия дебаффа |
| **МЛ** | Канал **4 сек**; с apex даёт **2 заряда** — можно копить под тринкет / босса | каждый тик даёт **Заморозку** |
| **ЛШ** | Летит вперёд **15 сек**; у **Чаромета** осколки ускоряют КД | главный AoE-кулдаун |
| **2 цели** | Всё ещё **ST-ротация** на приоритетную | AoE-приоритет — с **3+** целей |

> **Разрушение** (*Shatter*): при расходе стаков **ЛК** / **КБ** / **ЛШип** бьёт цель и наносит меньший урон рядом стоящим. Если цель умирает со стаками — взрыв по AoE (*Winter's End*).

## Простое правило «что жать сейчас?» (M+)

1. Есть **Заморозка мозгов**? → **[Шквал](https://www.wowhead.com/ru/spell=44614)**.
2. Есть **Ледяные пальцы**? → **[Ледяное копье](https://www.wowhead.com/ru/spell=30455)**.
3. **≥6** (Чаромет) / **≥10** (Ледяной огонь) стаков **Заморозки**? → **ЛК**.
4. **КБ** / **ЛШип** / **ЛШ** готовы? → жмите.
5. **МЛ** готов и стаки потрачены? → канал + тринкеты на приоритетной цели.
6. **3+** целей и мгновенная **СБ**? → **СБ**.
7. Иначе → **ЛС** / **СЛО** (не стойте без дела).

# ЧАСТЬ 2. Таланты, статы, экипировка

## Герой-талант: Чаромет vs Ледяной огонь

| | **Чаромет** (*Spellslinger*) | **Ледяной огонь** (*Frostfire*) |
|---|------------------------------|----------------------------------|
| **M+ по умолчанию** | **да** — стабильнее, чаще **ЛШ**, проще ротация | чуть **burstier**, но **слабее** в ключах |
| **Стиль** | осколки ускоряют **ЛШ**; **ЛК** с **6** стаков | **СЛО**, **КБ**, взрывной AoE; **ЛК** с **10** стаков |
| **Сильные стороны** | предсказуемый урон пак за паком | быстрый урон по мелким пакам / открытому миру |
| **Слабости** | меньше «взрыва» на коротких пулах | ниже средний DPS в высоких ключах |

**Импорт (Чаромет, M+/AoE):**  
`CAEAAAAAAAAAAAAAAAAAAAAAAYGGLzMzsMmZmYmxMzMzMziZmZMjZAAAgZmZWWmZaDAA2AAAAWAYbbMzMDmthxMsAAAwMbAzADYGMA`

**Импорт (Ледяной огонь, M+/AoE):**  
`CAEAAAAAAAAAAAAAAAAAAAAAAMzwYZmZmFmZmYGmZmZmZWMzMzMGzsMTzMLzCAAAaBAAWAAAAWAYbbMzMDGGzMzYDAAAMzgZyYAgB`

Калькулятор: [Wowhead RU — маг, лед](https://www.wowhead.com/ru/talent-calc/mage/frost).

**Частые замены в M+:**
- **Одинокая зима** (*Lonely Winter*) ↔ **Призыв элементаля воды** — **~1%** ST vs **~1%** AoE; элементаль даёт **Заморозку** танку.
- В данже с проклятиями → **Снятие проклятия**; с укради-баффами → **Чарокрад** (иначе трата очков).
- Много фокус-урона → **Ледяное обострение** (*Frost Conditioning*) — **2** заряда **Ледяного холода** подряд.

**Apex (*Hand of Frost*):** пассивно усиливает **Разрушение**; **МЛ** получает **2-й заряд** — копите под тринкет или босса.

## Статы

### Главное правило

**ilvl важнее идеальных вторичных статов.** Посох / жезл + off-hand — самые ценные слоты после тринкетов.

### Приоритет (M+, оба героя)

1. **Интеллект**
2. **Искусность** — усиливает **Заморозку** и **Разрушение**
3. **Критический удар** — нет жёсткого капа
4. **Скорость** — быстрее **ЛС**, больше проков
5. **Универсальность**

> Веса **плавают** от экипировки — не стакайте одну вторичку в ноль. Для BiS прогоните [Raidbots](https://www.raidbots.com/).

## Приоритет ротации (кратко)

### Чаромет — single target / приоритетная цель (2 цели тоже ST)

1. **КБ**.
2. **Шквал** с **ЗМ**; если **ЛБ** не активна — второй **Шквал** с **ЗМ**.
3. **ЛШ**.
4. **ЛК** с **ЛП**.
5. **ЛШип**.
6. **ЛК** при **≥6** стаках **Заморозки**.
7. **МЛ**.
8. **Шквал** (заряд без **ЗМ**).
9. **ЛС**.

### Чаромет — AoE (3+ целей)

1. **КБ**.
2. **СБ**, если активна мгновенная каста (*Freezing Rain*).
3. **Шквал** с **ЗМ** (логика **ЛБ** — как в ST).
4. **ЛШ**.
5. **ЛК** с **ЛП**.
6. **ЛШип**.
7. **ЛК** при **≥6** стаках.
8. **Кольцо обледенения** / **Конус холода**.
9. **СБ** при **5+** целях.
10. **Шквал** → **МЛ** → **ЛС**.

> В M+ **не ждите** идеального AoE: держите **одну** приоритетную цель — cleave приходит от **Разрушения**.

### Ледяной огонь — отличия

- Заполнитель: **СЛО** вместо **ЛС**.
- **ЛК** при **≥10** стаках (не **6**).
- AoE: больше **СБ** на **3–6** целях; **Конус холода** сейчас слаб — не приоритет.

### Кулдауны — как не терять DPS

- **МЛ** — **2 заряда**: один на пак, второй — под тринкет / босса.
- **ЛШ** — не копите «на босса» в M+; у **Чаромета** осколки и так ускоряют КД.
- **МЛ** кастуйте **после** расхода стаков — иначе переполните **Заморозку**.
