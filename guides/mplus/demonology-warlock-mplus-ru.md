# ЧАСТЬ 1. Для тех, кто играет впервые

## Что вы делаете одной фразой

1. Генерируете **осколки души** (**СТ**, **ДЗ**, **АС**, проки **ДЯ**).
2. Тратите ОД на **РГ** → появляются **бесы**; держите **ЗО** и гримуары по КД.
3. В бурст: **Страж** → **ГВБ** → **ГРС** → **Тиран** → максимум **РГ** в окне тирана.
4. В AoE: **Импл.** с **≥6** бесами (с талантом **To Hell and Back** — и в cleave на 2–3 цели).
5. Между пулами **не сжигайте** все ОД в **Импл.** — выходите с **3 ОД** и бесами для быстрого старта.

## Две «валюты» на экране

| Ресурс | Правило | Почему |
|--------|---------|--------|
| **Осколки души** (до **5**) | Не копите выше **4–5** без плана; тратьте на **РГ** / призывы | кап = потеря генерации |
| **Демоническое ядро** (до **4**) | Держите **≤2** стаков в обычной ротации; перед **Тираном** — **≥2** | иначе теряете проки; нужны для быстрого набора ОД в окне |
| **Бесы** | **Импл.** при **≥6**; перед **ВС** — **≥2** беса | cleave и генерация **ДЯ** |
| **Переход между пулами** | Вне боя восстановите **3 ОД**; не **Импл.** «в пустоту» в конце пака | иначе долгий «прогрев» на новом пуле |

> **Бесы** при движении выстраиваются **перпендикулярно** направлению взгляда — **стрейфите**, чтобы не агрить лишних мобов. На сложных маршрутах **отзовите** **[стража Скверны](https://www.wowhead.com/ru/spell=30146)**.

## Кнопки на панели — что делает каждая

| Приоритет | Способность | Когда |
|-----------|-------------|-------|
| Бурст | **ГВБ** → **ГРС** → **Тиран** → **Страж** | танк держит пак; расовые + тринкеты в **Тиран** |
| Высокий | **РГ** при **4–5** ОД | не копите без причины |
| Высокий | **ЗО** | по КД (с 4p тир-сета — почти всегда) |
| Высокий | **Импл.** | **≥6** бесов; **≤2** **ДЯ** перед взрывом |
| Средний | **ВС** | **≤2** **ДЯ** и **≥2** беса |
| Средний | **ДЗ** | **≥2** стака **ДЯ** |
| Средний | **АС** / **СТ** | **≤2** ОД или заполнитель |
| Утилити | **Метание топора**, **Неистовство Тьмы**, **Вой ужаса** | прерывание / стоп кастов |

## Первый пул — опенер (M+)

Перед боем: **[Призыв стража Скверны](https://www.wowhead.com/ru/spell=30146)**, питомец на **«Пассивность»** (не **«Угроза»**).

1. Прекаст **2×** **[Демонический заряд](https://www.wowhead.com/ru/spell=264178)** (если есть **ДЯ**).
2. Прекаст **[Вытягивание сил](https://www.wowhead.com/ru/spell=264130)** (**≥2** беса).
3. Прекаст **[Стрела Тьмы](https://www.wowhead.com/ru/spell=686)**.
4. **СТ** → **[Призыв стража ужаса](https://www.wowhead.com/ru/spell=18540)**.
5. **ГВБ** → **ГРС** + расовые + тринкеты.
6. **2–4×** **СТ** (до **≤2** ОД).
7. **ЗО** → **Тиран**.
8. Спам **РГ** в окне **Тирана**.
9. **Импл.** (**≥6** бесов, **≤1** **ДЯ**).
10. **ВС** после второй **РГ**.
11. Дальше — [приоритет ротации](#приоритет-ротации-кратко).

**Макрос бурста:**

```
#showtooltip Призыв демонического тирана
/cast Гримуар: властелин бесов
/cast Гримуар: разоритель Скверны
/cast Призыв демонического тирана
/use 13
/use 14
```

## Простое правило «что жать сейчас?» (M+)

1. **Тиран** / **Страж** / гримуары готовы и танк держит пак? → бурст (п. 1–8 опенера).
2. **≥6** бесов и **≤2** **ДЯ**? → **Импл.**
3. **≤2** **ДЯ** и **≥2** беса? → **ВС**
4. **ЗО** готов? → **ЗО**
5. **≥4** ОД? → **РГ**
6. **≥2** **ДЯ**? → **ДЗ**
7. **≤2** ОД? → **АС** / **СТ**
8. Иначе → **СТ** (не стойте без дела — генерируйте ОД).

## Герой-талант: Диабolist vs Жнец душ

| | **Диабolist** (*Diabolist*) | **Жнец душ** (*Soul Harvester*) |
|---|-----------------------------|----------------------------------|
| **M+ по умолчанию** | **да** — сильнее AoE и burst на больших паках | для **низких** ключей / мелких пулов |
| **Стиль** | **Импл.**, **Ruination**, **Cloven Souls** | быстрее старт **Apex** (*Dominion of Argus*), больше **ДЯ** |
| **Сильные стороны** | burst на **5+** целях, предсказуемый cadence | лучше **1–3** цели, сильнее execute-эффекты |

## Статы

### Главное правило

**ilvl важнее идеальных вторичных статов.** Разница между вторичками небольшая — не отказывайтесь от апгрейда ради «идеального» статa.

### Приоритет (M+, **Диабolist**, AoE)

1. **Интеллект**
2. **Критический удар**
3. **Скорость** / **Искусность** (близки по ценности)
4. **Универсальность**

> **Искусность** усиливает **всех** демонов и **Импл.** — особенно ценна в AoE. **Скорость** ускоряет касты и атаки питомцев (кроме бесов с фиксированным числом **firebolt**). **Крит** синергирует с талантами вроде *Demonic Brutality*.

### Кулдауны — как не терять DPS

- **Тиран** — на **каждом** нормальном паке; не «копите» на воображаемый мега-пак **>3 мин**.
- **Страж** + гримуары — вместе с **Тираном** или непосредственно перед ним.
- **Импл.** — не в последнюю секунду пака, если теряете **ОД** на следующем.
- Между пулами: **3 ОД** вне боя → мгновенный **РГ** / **Тиран** на старте.

## Приоритет ротации (кратко)

**Single target / приоритетная цель:**

1. **ГВБ** → **ГРС** → **Тиран** → **Страж** (+ тринкеты / расовые).
2. **ВС** (**≤2** **ДЯ**, **≥2** беса).
3. **Импл.** (**≥6** бесов, с **To Hell and Back**).
4. **ЗО**.
5. **РГ** (**4–5** ОД).
6. **ДЗ** (**≥2** **ДЯ**).
7. **АС** (**≤2** ОД) → **СТ**.

**AoE (M+):** тот же приоритет; **Импл.** — чаще и агрессивнее. **РГ** на приоритетную цель (больше HP / опасный моб). Не **Импл.** в конце пака «в никуда».

**Пороги:**

| Ситуация | Действие |
|----------|----------|
| **≥6** бесов, **≤2** **ДЯ** | **Импл.** |
| **≤2** **ДЯ**, **≥2** беса | **ВС** |
| **≥4** ОД | **РГ** |
| **≥2** **ДЯ** | **ДЗ** |
| **≤2** ОД | **АС** / **СТ** |
| Перед **Тираном** | **≥2** **ДЯ**, **≥3** ОД |
