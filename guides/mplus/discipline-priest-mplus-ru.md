# ЧАСТЬ 1. Для тех, кто играет впервые

## Что вы делаете одной фразой

1. Вешаете **[Искупление вины](https://www.wowhead.com/ru/spell=194384)** на группу (**Исповедь**, **СС:Щит**, **СС:Сияние**, **Мольба** и др.).
2. Наносите урон (**СТ:Боль**, **СТ:Смерть**, **Кара**, **ВР**) — часть урона лечит всех с **Искуплением**.
3. Крутите **[Исповедь](https://www.wowhead.com/ru/spell=47540)** по КД: прок **[Щита Б.](https://www.wowhead.com/ru/spell=1253593)**, размазывание **СТ:Боли** по паку, ST-хил.
4. Между **Исповедями** жмите **[Слово силы: Щит](https://www.wowhead.com/ru/spell=17)** (таланты **Weal and Woe** / **Eternal Barrier**).
5. На прок **[Темного восстановления](https://www.wowhead.com/ru/spell=186263)** — срочный хил раненому (частые проки в M+ при многих дотах).

> **Послушание** в S1 Midnight — это в первую очередь **Щит Бездны** и **Темное восстановление**, а не «чистое» **Искупление** через урон. Урон всё ещё важен, но щиты и проки несут основную нагрузку.

## Искупление вины и Щит Бездны

| Механика | Правило |
|----------|---------|
| **Искупление вины** | Урон с **Искуплением** на цели → хил этой цели. **Внешний** урон (тринкеты, расовые) **не** лечит. |
| **Щит Б.** | После **Исповеди** шанс усилить следующий **СС:Щит** (**Постижение тьмы**). Сильнее обычного щита, брызгает на **2** соседей, отражает урон → ещё хил. |
| **«Колода» проков** | Каждые **3** каста **Исповеди** — **гарантированно** один **Щит Б.** (но неизвестно, на каком из трёх). Можно держать прок под урон. |
| **Исповедь** | На союзнике — **Искупление** + хил; на враге — урон + размазывание **СТ:Боли** (важно в M+). |
| **Не копите** **СС:Щит** | Между **Исповедями** тратьте заряд **СС:Щит** — не теряйте КД и **Weal and Woe**. |

## Кнопки на панели — что делает каждая

| Приоритет | Способность | Когда |
|-----------|-------------|-------|
| Высший | **Щит Б.** (прок) | **до** следующей **Исповеди**; на себя/танка под урон |
| Высший | **Т.восст.** (прок) | раненый без полного HP |
| Высокий | **Исповедь** | по КД: союзник (хил) или враг (доты/урон) |
| Высокий | **СС:Щит** | между **Исповедями**, не капить КД |
| Средний | **СТ:Боль** | на всех врагов пака |
| Средний | **СТ:Смерть** | по КД; снайп &lt;20% HP в паке |
| Бурст | **Проповедь** + **СС:Сияние** | перед/во время тяжёлого урона |
| По ситуации | **Искр.раскаяние** | большой пак + **Искупление** на группе |
| Заполнитель | **Кара**, **ВР** | когда нечего важнее |

## Первый пул — опенер (M+)

Перед боем: **[Слово силы: Стойкость](https://www.wowhead.com/ru/spell=21562)**.

**Ясновидец, стандарт M+:**

1. **[Слово Тьмы: Боль](https://www.wowhead.com/ru/spell=589)** на приоритетную цель (или прекаст).
2. **[Исповедь](https://www.wowhead.com/ru/spell=47540)** на **танка** (или самого раненого).
3. **[Слово силы: Щит](https://www.wowhead.com/ru/spell=17)** на танка.
4. Если есть прок — **[Щит Бездны](https://www.wowhead.com/ru/spell=1253593)** на танка/себя.
5. **[Исповедь](https://www.wowhead.com/ru/spell=47540)** по **врагу** (размазать **СТ:Боль**).
6. **[Слово Тьмы: Смерть](https://www.wowhead.com/ru/spell=32379)**.
7. Дальше — [приоритет ротации](#приоритет-ротации-кратко).

> На первом пуле не ждите «идеального» окна для **Проповеди** — если группа уже получает урон, **Проповедь** + **СС:Сияние** сразу.

---

## Простое правило «что жать сейчас?» (M+)

1. Есть прок **Щита Б.**? → наложите **до** следующей **Исповеди**.
2. Есть прок **Т.восст.** и раненый? → **Т.восст.**
3. **Исповедь** готова? → союзник (хил) или враг (пак без дотов).
4. **СС:Щит** готов и нет прока **Щита Б.**? → на танка/раненого.
5. Нет **СТ:Боли** на врагах? → **СТ:Боль** / **Исповедь** по врагу.
6. **СТ:Смерть** по КД.
7. Грядёт большой урон? → **Проповедь** → **СС:Сияние** (×2).
8. Иначе → **Кара** / **ВР**.

# ЧАСТЬ 2. Таланты, статы, экипировка

## Герой-талант: Ясновидец vs Ткач Бездны

| | **Ясновидец** (*Oracle*) | **Ткач Бездны** (*Voidweaver*) |
|---|---------------------------|--------------------------------|
| **M+ по умолчанию** | **да** — **Щит Б.**, **Т.восст.**, сильный ST | альтернатива; слабее после нерфов **Искупления** |
| **Стиль** | **Исповедь** на союзников, **СС:Щит**, проки | **Искупление** через урон, **Энтропический разлом**, питомцы |

| **Слабости** | меньше «чистого» AoE-DPS | слабее ST, нужны тайминги **ВР** |

## Статы

### Главное правило

**ilvl важнее идеальных вторичных статов.** Все вторички близки по ценности — берите выше уровень предмета.

### Приоритет (M+, **Ясновидец**)

1. **Интеллект**
2. **Скорость**
3. **Критический удар**
4. **Искусность** (*Искусность: Благодать* — усиливает хил с **Искуплением**)
5. **Универсальность**

### Приоритет (M+, **Ткач Бездны**)

Тот же порядок: **Скорость** → **Крит** → **Искусность** → **Универсальность**.

> На очень высоких ключах иногда качают **Универсальность** ради снижения урона — это **минус HPS**. Для большинства ключей не копируйте.

## Приоритет ротации (кратко)

**Ясновидец, M+ (общий приоритет):**

1. **Щит Б.** (прок) → **до** следующей **Исповеди**.
2. **Т.восст.** (прок) на раненого.
3. **СТ:Боль** на врагах без дота.
4. **СТ:Смерть** по КД (&lt;20% — приоритет).
5. **Исповедь** — союзник (хил/**Искупление**) или враг (доты).
6. **СС:Щит** между **Исповедями**.
7. **Проповедь** → **СС:Сияние** (×1–2) под урон.
8. **Искр.раскаяние** по врагам при **Искуплении** на группе.
9. **ВР** / **Кара**.

**Тяжёлый урон по группе:**  
**Проповедь** → **СС:Сияние** ×2 → **Исповедь** на танка → **СС:Щит** / **Щит Б.** → урон по паку.

**Тяжёлый ST-урон (танк):**  
**Подавл.боли** → **Исповедь** → **СС:Щит** / **Щит Б.** → **Т.восст.**
