ЧАСТЬ 1. Для тех, кто играет впервые

Что вы делаете одной фразой

1. Вешаете Искупление вины на группу (Исповедь, СС:Щит, СС:Сияние, Мольба и др.).

2. Наносите урон (СТ:Боль, СТ:Смерть, Кара, ВР) — часть урона лечит всех с Искуплением.

3. Крутите Исповедь по КД: прок Щита Б., размазывание СТ:Боли по паку, ST-хил.

4. Между Исповедями жмите Слово силы: Щит (таланты Weal and Woe / Eternal Barrier).

5. На прок Темного восстановления — срочный хил раненому (частые проки в M+ при многих дотах).

Послушание в S1 Midnight — это в первую очередь Щит Бездны и Темное восстановление, а не «чистое» Искупление через урон. Урон всё ещё важен, но щиты и проки несут основную нагрузку.

Искупление вины и Щит Бездны

МеханикаПравило
Искупление виныУрон с Искуплением на цели → хил этой цели. Внешний урон (тринкеты, расовые) не лечит.
Щит Б.После Исповеди шанс усилить следующий СС:Щит (Постижение тьмы). Сильнее обычного щита, брызгает на 2 соседей, отражает урон → ещё хил.
«Колода» проковКаждые 3 каста Исповеди — гарантированно один Щит Б. (но неизвестно, на каком из трёх). Можно держать прок под урон.
ИсповедьНа союзнике — Искупление + хил; на враге — урон + размазывание СТ:Боли (важно в M+).
Не копите СС:ЩитМежду Исповедями тратьте заряд СС:Щит — не теряйте КД и Weal and Woe.

Первый пул — опенер (M+)

Перед боем: Слово силы: Стойкость.

Ясновидец, стандарт M+:

1. Слово Тьмы: Боль на приоритетную цель (или прекаст).

2. Исповедь на танка (или самого раненого).

3. Слово силы: Щит на танка.

4. Если есть прок — Щит Бездны на танка/себя.

5. Исповедь по врагу (размазать СТ:Боль).

6. Слово Тьмы: Смерть.

7. Дальше — приоритет ротации.

На первом пуле не ждите «идеального» окна для Проповеди — если группа уже получает урон, Проповедь + СС:Сияние сразу.

Простое правило «что жать сейчас?» (M+)

1. Есть прок Щита Б.? → наложите до следующей Исповеди.

2. Есть прок Т.восст. и раненый? → Т.восст.

3. Исповедь готова? → союзник (хил) или враг (пак без дотов).

4. СС:Щит готов и нет прока Щита Б.? → на танка/раненого.

5. Нет СТ:Боли на врагах? → СТ:Боль / Исповедь по врагу.

6. СТ:Смерть по КД.

7. Грядёт большой урон? → Проповедь → СС:Сияние (×2).

8. Иначе → Кара / ВР.

Калькулятор: Wowhead RU — жрец, послушание.

Частые замены в M+:

  • Массовое рассеивание — под аффикс Ascendant и данжи с магией.
  • Очищение от болезни (улучшенное Очищение) — Devour, Пещеры Маисара.
  • Сковывание кошмара — нежить/аберрации (Яма Сарона и др.).
  • Вхождение в Бездну — снижение урона при Уходе в тень.

Статы

Главное правило

ilvl важнее идеальных вторичных статов. Все вторички близки по ценности — берите выше уровень предмета.

Приоритет (M+, Ясновидец)

1. Интеллект

2. Скорость

3. Критический удар

4. Искусность (*Искусность: Благодать* — усиливает хил с Искуплением)

5. Универсальность

Приоритет (M+, Ткач Бездны)

Тот же порядок: Скорость → Крит → Искусность → Универсальность.

На очень высоких ключах иногда качают Универсальность ради снижения урона — это минус HPS. Для большинства ключей не копируйте.

Приоритет ротации (кратко)

Ясновидец, M+ (общий приоритет):

1. Щит Б. (прок) → до следующей Исповеди.

2. Т.восст. (прок) на раненого.

3. СТ:Боль на врагах без дота.

4. СТ:Смерть по КД (&lt;20% — приоритет).

5. Исповедь — союзник (хил/Искупление) или враг (доты).

6. СС:Щит между Исповедями.

7. Проповедь → СС:Сияние (×1–2) под урон.

8. Искр.раскаяние по врагам при Искуплении на группе.

9. ВР / Кара.

Тяжёлый урон по группе:

Проповедь → СС:Сияние ×2 → Исповедь на танка → СС:Щит / Щит Б. → урон по паку.

Тяжёлый ST-урон (танк):

Подавл.боли → Исповедь → СС:Щит / Щит Б. → Т.восст.
