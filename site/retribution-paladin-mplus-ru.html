ЧАСТЬ 1. Для тех, кто играет впервые

Что вы делаете одной фразой

1. Генерируете Силу Света (КС, Удар воина Света, Правосудие, ИС, ББ и автоатаки с Крестовыми ударами).

2. Тратите СС на Окончательный приговор (одна цель) или Божественную бурю (3+ врагов).

3. В бурст (Храмовник, M+): Гнев карателя → Смертный приговор (если в билде) → Испепеляющий след → Молот Света → ОП / ББуря → Божественный благовест.

4. При проке Искусства войны — Клинок справедливости выше обычного приоритета (apex Свет в душе).

5. Не капайте 5 СС без плана; не держите ГК «на идеальный пак» — в ключах лучше лишний бурст на среднем пуле.

Воздаяние в M+ — мощные всплески каждые ~1–2 мин + сильная групповая утилита (сейвы, ресс, аура). Урон «между окнами» скромнее, чем у чистых ranged-DPS — это нормально.

Первый пул — опенер (M+)

Если есть Алгет'арская шкатулка с секретом — канал ~2 сек до пула (или за ~2 сек до ГК).

Храмовник, стандарт M+ (со Смертным приговором):

1. Клинок справедливости.

2. Гнев карателя.

3. Потенциал Света + on-use тринкеты.

4. Смертный приговор.

5. Испепеляющий след.

6. Молот Света.

7. Окончательный приговор × 2.

8. Божественный благовест.

9. Дальше — приоритет ротации.

С Сияющей войной вместо СП: шаг 4 пропустите — ГК даст Испепеляющий след раньше; жмите ИС сразу после ГК.

Макрос бурста:


#showtooltip Гнев карателя

/cast Гнев карателя

/cast Смертный приговор

/use 13

/use 14

Простое правило «что жать сейчас?» (M+)

1. ИВ на КС? → КС (даже на 4 СС).

2. МС готов и есть 5 СС? → МС (особенно в ГК / СП).

3. ГК готов и танк держит пак? → ГК → СП → ИС → МС → траты СС.

4. 3+ врагов? → ББуря; иначе → ОП на 3–5 СС.

5. ИС / ББ по КД — не копите «на босса», если пак живёт ≥10 сек.

6. Укор и Слепящий свет важнее, чем «дожать» последний ОП на адде.

Импорт (M+, Храмовник, приоритетная цель / Смертный приговор): возьмите на Icy Veins — M+ Execution Sentence (вкладка *Templar Execution Sentence*).

Калькулятор: Wowhead RU — паладин, воздаяние.

Частые замены в M+ (Храмовник):

  • Tempest of the Lightbringer вместо Jurisdiction — больше AoE (ББуря уже с 2 целей).
  • Смертный приговор вместо Сияющей войны — funnel на приоритетную цель (высокие ключи).
  • Клинок возмездия + Sanctify — cleave-паки.
  • Blinding Light (талант) — Слепящий свет бьёт по AoE (аффикс Ascendant).
  • Turn Evil — Изгнание зла на нежить/демонов.

Apex Свет в душе: прок ИВ → КС +150% урона + волна AoE; в ГК траты СС сильнее. Не перезаписывайте прок лишним КС без ИВ.

Статы

Главное правило

ilvl важнее идеальных вторичных статов. Сила на 2H-оружии даёт больше, чем на любом другом слоте.

Приоритет (M+, Храмовник)

1. Сила

2. Искусность — усиливает весь святой урон

3. Критический удар — ценнее в AoE (Wrathful Descent)

4. Скорость — быстрее Крестовые удары и КД генераторов

5. Универсальность

Точный порядок вторичек плавает от экипировки — для BiS прогоните Raidbots. Жёстких брейкпоинтов нет.

Кулдауны — как не терять DPS

  • ГК — на любом паке ≥15 сек; внутри — СП → ИС → МС → ББ.
  • ИС / ББ — по КД, не «копите на босса» в M+.
  • С СП активным — продолжайте AoE-ротацию; урон СП считает весь урон по целям.
  • Шкатулка: канал до ГК, не после.

Single target / приоритетная цель

1. Молот Света с проком *Light's Deliverance* (если скоро кончится ГК / СП).

2. Клинок справедливости с ИВ (apex Свет в душе).

3. Молот Света при 5 СС.

4. Окончательный приговор при 3–5 СС.

5. Испепеляющий след / Божественный благовест по КД.

6. Клинок справедливости, Правосудие, Молот гнева — генераторы.

AoE (M+)

1. ИВ → КС (можно с Клинком возмездия).

2. МС / ББуря / ОП — как в ST, но ББуря при 3+.

3. ИС + ББ по КД.

4. Не капите СС на AoE — ББуря часто важнее «идеального» ОП.
